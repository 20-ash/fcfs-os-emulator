## Compiling and Running Instructions in Visual Studio Code

Prerequisites:

1. MinGW‑w64 (g++ compiler) installed and added to system PATH
2. Project folder fcfs-os-emulator opened in VS Code

### MacOS

To compile:
`g++ -std=c++20 emulator.cpp -o emulator`

To run:
`./emulator`

### Windows

To compile:
`g++ -std=c++20 emulator.cpp -o emulator.exe`

To run:
`emulator.exe`
